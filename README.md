# Personal Portfolio Website

This repository contains the source code for my personal portfolio website. The website serves as an introduction to who I am, my background in Computer Science, my technical interests, and the projects I have worked on. It was created as part of an academic assignment and also serves as a foundation for my online professional presence.

The site is built using basic web technologies and is hosted using GitHub Pages.

---

## Live Website

You can view the live website here:  
https://afroootat.github.io/

---

## About the Website

The website includes the following sections:

- A hero section that introduces me and my career direction
- An About Me section describing my background, interests, and goals
- A skills section highlighting my technical and soft skills
- A projects section showcasing selected work and practice projects
- A contact section with links to reach or connect with me

The content is designed to be simple, clear, and easy to navigate.

---

## Technologies Used

- HTML for structure and content
- CSS for styling and layout
- JavaScript for basic interactivity
- Git and GitHub for version control and hosting
- GitHub Pages for deployment

---

## Project Purpose

This project was created to:

- Practice building and structuring a complete website
- Learn how to deploy a static site using GitHub Pages
- Create a professional online presence
- Serve as a base that can be improved and expanded over time

---

## Setup and Usage

To view the project locally:

1. Clone this repository
2. Open the `index.html` file in a web browser

No additional setup is required.
